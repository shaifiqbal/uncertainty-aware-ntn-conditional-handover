# Uncertainty-Aware Conditional Handover Timing in 5G NR LEO NTN

Simulation code and reproducibility materials for a risk-aware conditional-handover
timing policy in 5G NR LEO non-terrestrial networks, evaluated via Monte Carlo simulation
against fixed-guard-time, point-prediction, and quality-threshold baselines.

Status: work in progress — target submission ISETC'26 (Timișoara, Romania).

## Repository structure
- `data/tle_archive/` — archived TLE data (source, timestamp, checksum logged)
- `src/` — simulation code
- `config/` — scenario configuration files
- `results/` — raw simulation outputs (CSV/Parquet)
- `figures/` — generated plots
- `tests/` — sanity checks
- `literature/` — literature matrix export
